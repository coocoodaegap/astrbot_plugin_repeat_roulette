# AstrBot 复读轮盘赌插件 (Repeat Roulette)

这是一个充满“惊喜”的 AstrBot 插件。当群聊中出现复读行为时，它会默默记录，并在复读链断掉的那一刻，干掉第 N 个复读的人。

## 功能介绍
- **复读检测**：自动记录群聊中的复读消息。
- **精准背刺**：复读被打断时，禁言倒数第 N 个复读的用户。
- **可配置性**：支持自定义禁言目标 `last_n_th` 和禁言时长 `ban_duration`。

## 配置项
- `last_n_th`: 第几个复读的人会被禁言（默认为 1，即最后一个复读的人）。
- `ban_duration`: 禁言时长（单位：秒，默认 60 秒）。

## 注意事项
- 本插件**仅适用于使用 `aiocqhttp` 适配器的平台**。
- 请确保机器人拥有群管理权限，否则禁言功能将失效。
- 建议谨慎开启，以免引起群友“物理意义”上的不满。
