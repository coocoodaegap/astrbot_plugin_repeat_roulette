# AstrBot 复读轮盘赌插件 (Repeat Roulette)

这是一个充满“惊喜”的 AstrBot 插件。当群聊中出现复读行为时，它会默默记录；复读链被新消息打断时，轮盘才会结算。

## 功能介绍

- **复读入膛**：每一次相同文本的复读都会向本轮队列加入一个位置；同一成员多次复读会保留多次位置。
- **概率轮盘**：达到最低复读次数后，本轮会在被打断时结算。复读越多，实弹率越高，直到上限。
- **加权抽取**：随机模式下从队列随机抽人，因此复读越多的人既会抬高全局实弹率，也会有更多被抽中的位置。
- **空包与卡壳**：空包会公开播报；机器人没有禁言权限或接口调用失败时，会播报卡壳而不让状态卡住。
- **超时熄火**：长时间没有新消息的复读轮会静默失效，避免隔很久后误触发。

## 配置项

- `random_mode`: 是否随机抽取目标（默认开启）。开启时，同一人的多次复读会提高其被抽中的概率。
- `last_n_th`: 关闭随机模式时，选择倒数第 N 次复读（默认 1，即最后一次）。
- `min_repeat_count`: 至少多少次复读后才结算（默认 2）。
- `base_bullet_chance`: 刚达到最低复读次数时的实弹率（默认 20%）。
- `chance_per_repeat`: 超过门槛后每多一次复读增加的实弹率（默认 15%）。
- `max_bullet_chance`: 实弹率的封顶值（默认 80%）。
- `round_timeout_seconds`: 当前复读轮多久未活动便静默作废（默认 180 秒）。
- `ban_duration`: 实弹命中后的禁言时长（单位：秒，默认 60 秒）。

## 注意事项

- 本插件**仅适用于使用 `aiocqhttp` 适配器的平台**。
- 请确保机器人拥有群管理权限，否则实弹命中会播报为“卡壳”。
- 当前只匹配文本消息；首尾或连续空白的不同不会打断同一轮。
- 建议先把实弹率设低一些，确认群友都玩得起再逐步提高。
